# CyberRisk360

CyberRisk360 is a beginner-friendly cybersecurity Governance, Risk, and Compliance (GRC) project. Its purpose is to provide a simple, approachable way to learn how organizations identify risks, document controls, monitor compliance, and communicate their cybersecurity posture.

## Planned features

Future phases are planned to introduce:

- Risk identification and assessment
- Risk register management
- Security control tracking
- Compliance framework mapping
- Dashboard visualizations
- GRC report generation

These features are plans only and are not implemented in Phase 0.

## Technology stack

- Python
- Streamlit
- pandas
- Plotly

## Current status

**Phase 0 — Project setup**

The initial folder structure, dependency list, Git ignore rules, and a basic Streamlit welcome page are in place. No advanced application or GRC features have been built yet.

To run the welcome page after installing the dependencies:

```powershell
pip install -r requirements.txt
streamlit run app.py
```
